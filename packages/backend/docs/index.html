Portfolio Dashboard Backend API Documentation

This document provides details about the API endpoints for the Portfolio Dashboard Backend application. The backend is built using Node.js, Koa, and SkewerDB.

Dashboard

Holdings

PUT /holdings

Description: Creates a new holding record.

Request Body (Example):

        
{
    "accountId": "john",
    "name": "New Stock",
    "symbol": "NEWSTOCK",
    "qty": 10,
    "averagePrice": 50,
    "type": "stock"
}

Response: Returns the newly created holding object.

GET /holdings

Description: Retrieves all holding records.

Request: None

Response: Returns an array of holding objects.

GET /holdings/:id

Description: Retrieves a specific holding record by ID.

Request Parameters:

  • id: Holding ID (UUID)

Response: Returns a single holding object.

POST /holdings

Description: Updates an existing holding record.

Request Body (Example):

        
{
    "id": "existing-holding-id",
    "accountId": "john",
    "name": "Updated Stock Name",
    "symbol": "UPDATEDSTOCK",
    "qty": 15,
    "averagePrice": 55,
    "type": "stock"
}

Response: Returns the updated holding object.

DELETE /holdings/:id

Description: Deletes a specific holding record by ID.

Request Parameters:

  • id: Holding ID (UUID)

Response: Returns a success message.

        
{ message: 'Holding deleted successfully' }

POST /holdings/buy

Description: Completes a buy transaction, updating or creating a holding and logging the transaction.

Request Body (Example):

        
{
    "accountId": "john",
    "symbol": "AAPL",
    "qty": 5,
    "averagePrice": 240,
    "type": "stock"
}

Response: Returns the updated or created holding object.

POST /holdings/sell

Description: Completes a sell transaction, updating or deleting a holding and logging the transaction.

Request Body (Example):

        
{
    "accountId": "john",
    "symbol": "AAPL",
    "qty": 2,
    "averagePrice": 245,
    "type": "stock"
}

Response: Returns the updated or deleted holding object.

POST /holdings/import

Description: Imports multiple holdings from an array of holding objects.

Request Body (Example):

        
[
  {
    "symbol": "AAPL",
    "name": "Apple Inc.",
    "qty": "100",
    "averagePrice": "$150.25",
    "accountId": "john",
    "type": "stock"
  },
  ...
]

Response: Returns a success message.

Live Data

GET /live/quote/:sym

Description: Retrieves live quote for a given stock or crypto symbol.

Request Parameters:

  • sym: Stock or Crypto symbol (e.g., AAPL, BTC). For Crypto use the base symbol (e.g., BTC for BTC-USDT).

Response (Example):

        
{
    "price": 236.87,
    "percentChange": 1.83,
    "dayHigh": 236.96,
    "dayLow": 230.68,
    "priceDate": "Feb 12, 2025 9:33 PM",
    "id": "AAPL",
    "createdAt": "...",
    "updatedAt": "..."
}

GET /live/recommendation/:sym

Description: Retrieves analyst recommendations for a given stock symbol.

Request Parameters:

  • sym: Stock symbol (e.g., AAPL).

Response (Example):

        
{
    "buy": 25,
    "hold": 13,
    "period": "2025-02-01",
    "sell": 3,
    "strongBuy": 12,
    "strongSell": 1,
    "id": "AAPL",
    "createdAt": "...",
    "updatedAt": "..."
}

GET /live/news/:sym

Description: Retrieves company news for a given stock symbol.

Request Parameters:

  • sym: Stock symbol (e.g., AAPL).

Response: Returns an array of news articles.

        
[
  {
    "category": "...",
    "datetime": 1718222400,
    "headline": "...",
    "id": 12345,
    "image": "...",
    "related": "...",
    "source": "...",
    "summary": "...",
    "url": "..."
  },
  ...
]

GET /live/history/:sym

Description: Retrieves historical price data for a stock symbol, used for charting.

Request Parameters:

  • sym: Stock symbol (e.g., AAPL).
  • range: Time range for historical data (e.g., 1d, 5d, 1M, 3M, 6M, 1y, 2y, 3y).

Response: Returns an array of price data points for candlestick charts.

        
[
  {
    "x": "2025-02-12T00:00:00.000Z",
    "y": [
      231.2,
      236.96,
      230.68,
      236.87
    ]
  },
  ...
]

Transactions

PUT /transactions

Description: Creates a new transaction record.

Request Body (Example):

        
{
    "accountId": "john",
    "symbol": "AAPL",
    "qty": 5,
    "price": 240,
    "type": "stock",
    "action": "buy"
}

Response: Returns the newly created transaction object.

GET /transactions

Description: Retrieves all transaction records.

Request: None

Response: Returns an array of transaction objects.

GET /transactions/:id

Description: Retrieves a specific transaction record by ID.

Request Parameters:

  • id: Transaction ID (UUID)

Response: Returns a single transaction object.

POST /transactions

Description: Updates an existing transaction record. (Functionality may not be fully implemented or necessary)

Request Body (Example):

        
{
    "id": "existing-transaction-id",
    "accountId": "john",
    "symbol": "AAPL",
    "qty": 6,
    "price": 242,
    "type": "stock",
    "action": "buy"
}

Response: Returns the updated transaction object.

DELETE /transactions/:id

Description: Deletes a specific transaction record by ID.

Request Parameters:

  • id: Transaction ID (UUID)

Response: Returns a success message.

Logs

GET /logs/:file

Description: Retrieves logs from a specified log file.

Request Parameters:

  • file: Log file name (e.g., combined, error).

Response: Returns the content of the log file as plain text.

DELETE /logs/:file

Description: Clears the content of a specified log file.

Request Parameters:

  • file: Log file name (e.g., combined, error).

Response: Returns the (now empty) content of the log file as plain text.
